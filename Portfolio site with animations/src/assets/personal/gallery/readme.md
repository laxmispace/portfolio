Drop your photos here - any `.jpg`, `.jpeg`, `.png`, or `.webp` file in this folder is picked up automatically by the WebGL gallery in the "about me" section (see `src/app/components/about/InfiniteCircularGallery.tsx`), no code changes needed.

- Files are loaded sorted by filename, so prefix them (`01-...`, `02-...`) if you want to control the order.
- Landscape or portrait both work - each photo is cropped to fill its card, centered.
- A handful of photos (5–10) works best; fewer than that repeats to fill out the carousel.
